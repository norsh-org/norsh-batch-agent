# Norsh Batch Agent

> Developed by Danthur Lice and contributors.\
> Copyright © 2024–2025 Norsh. All rights reserved.\
> Contact: dev (at) norsh.org

---

Command-line agent that signs and optionally transmits JSON batches to **Norsh-compliant endpoints**. The Norsh Batch Agent reads a private key (encrypted or not), computes deterministic signatures according to **NTP-3: Cryptography and Hash Specification**, and can either output the signed payload or send it to a Norsh API endpoint.

---

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=norsh-org_norsh-batch-agent\&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=norsh-org_norsh-batch-agent)

## Features

* Signs JSON batches using **ECDSA(secp384r1)** + **SHA3-384** digest
* Deterministic preimage creation: concatenates all `parameters`, `metadata`, and `publicKey` values sorted alphanumerically
* Supports **encrypted private keys** (AES-256-CBC + PBKDF2-HMAC-SHA3-384, 65,536 iterations)
* Fully compatible with keys generated by the [Norsh Key Generator](https://github.com/norsh-org/norsh-keygen-python)
* Accepts both plain and encrypted PEM (PKCS#8 / X.509)
* Can operate in **offline mode** (sign only) or **online mode** (sign and send)
* Automatic submission to API endpoint via HTTPS (supports `PRODUCTION` and `SANDBOX`)
* Graceful error handling and clear terminal messages
* **No dependencies on external wallets or libraries**

## Usage

### 1. **Clone and Install Dependencies**

```bash
git clone https://github.com/norsh-org/norsh-batch-agent.git
cd norsh-batch-agent
pip install cryptography pycryptodome requests
```

### 2. **Run the Batch Agent**

```bash
python norsh-batch-agent.py -k private.pem -p yourPassword -j data.json
```

Optional arguments:

| Flag             | Description                                             |
| ---------------- | ------------------------------------------------------- |
| `-k, --key`      | Path to private key file (PKCS#8, PEM)                  |
| `-p, --pwd`      | Password for private key (if encrypted)                 |
| `-j, --json`     | Input JSON array file                                   |
| `-n, --network`  | API network (default: `main`)                           |
| `-e, --endpoint` | Choose API endpoint (`SANDBOX` or default `PRODUCTION`) |
| `-s, --silent`   | Suppress banner output                                  |
| `-o, --output`   | Show JSON response from API                             |
| `-ns, --nosend`  | Sign only, output signed payload without sending to API |

Example:

```bash
python norsh-batch-agent.py -k private.pem -p test123 -j sample.json -e SANDBOX -ns
```

## Example Input

```json
[
  {
    "command": "module.notary.create",
    "version": 1,
    "parameters": {
      "xid": "0",
      "nounce": "123456",
      "name": "NAME"
    },
    "metadata": {
      "abc": "xyz",
      "xyz": "abc",
      "field": "111"
    }
  }
]
```

**Preimage Construction:**

```
PREIMAGE = sorted(values(parameters) + values(metadata) + values(publicKey)) joined by '|'
```

**Signature:**

```
SIGNATURE = Base64(ECDSA(secp384r1, SHA3-384(PREIMAGE)))
```

---

## Output

Each JSON object in the batch is augmented with:

```json
{
  "command": "...",
  ...,
  "publicKey": "Base64(X.509)",
  "signature": "Base64(ECDSA DER)",
}
```

The signed batch can either be printed locally (using `--nosend`) or sent automatically to the defined Norsh API endpoint (`https://api.norsh.org/{network}/v1/ucp`).

---

## Error Handling

* **Invalid password or corrupted key:** `> Failed to decrypt private key.`
* **Malformed JSON:** `> Failed to read or parse JSON input file.`
* **Network issues:** `> Error: Could not connect to the API server.`
* **Server timeout:** `> Error: Connection timed out while contacting the API server.`
